# Processamento Distribuído e Fundamentos de PySpark no Databricks

---

## Visão Geral

Este projeto contém o script inicial de fundamentação em Apache Spark utilizando a API PySpark no ambiente Databricks (Serverless Compute). O objetivo principal é demonstrar as operações essenciais de manipulação de DataFrames em grande escala.

---

## Funcionalidades e Operações Implementadas

- **Ingestão de Dados:** Criação e leitura de DataFrames estruturados a partir de dados tabulares.
- **Transformações Básicas:** Uso de métodos como `select`, `filter`, `withColumn` e `drop`.
- **Agregações e Filtros:** Aplicação de operações de agrupamento (`groupBy`) e agregações analíticas (`sum`, `avg`, `count`).
- **Tratamento de Esquemas:** Definição explícita de tipos de dados (`StructType` e `StructField`) para otimização de performance.

---

## Tecnologias Utilizadas

- **Linguagem:** Python / PySpark
- **Plataforma:** Databricks (Serverless Compute)
- **Engine:** Apache Spark

---

## Como Executar

O script `01_pyspark_basico.py` pode ser importado diretamente no Databricks para execução das operações de aprendizado do motor Spark.
