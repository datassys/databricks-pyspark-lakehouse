# Processamento Distribuido e Fundamentos de PySpark no Databricks

---

## Visao Geral

Este projeto contem o script inicial de fundamentacao em Apache Spark utilizando a API PySpark no ambiente Databricks (Serverless Compute). O objetivo principal e demonstrar as operacoes essenciais de manipulacao de DataFrames em grande escala.

---

## Funcionalidades e Operacoes Implementadas

* Ingestao de Dados: Criacao e leitura de DataFrames estruturados a partir de dados tabulares.
* Transformacoes Basicas: Uso de metodos como select, filter, withColumn e drop.
* Agregacoes e Filtros: Aplicacao de operacoes de agrupamento (groupBy) e agregacoes analiticas (sum, avg, count).
* Tratamento de Esquemas: Definicao explicita de tipos de dados (StructType e StructField) para otimizacao de performance.

---

## Tecnologias Utilizadas

* Linguagem: Python / PySpark
* Plataforma: Databricks (Serverless Compute)
* Engine: Apache Spark

---

## Como Executar

O script 01_pyspark_basico.py pode ser importado diretamente no Databricks para execucao das operacoes de aprendizado do motor Spark.
